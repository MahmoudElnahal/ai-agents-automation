### مشروعين: n8n Agricultural AI Agent + UiPath Email Triage Agent

> الكلام المكتوب بالخط العادي = اللي تقوله. اللي بين قوسين = اللي يتعرض على الشاشة.

---

## ⏱️ 0:00 – 0:30 — المقدمة

*(شاشة: رسمة أو الاتنين جنب بعض)*

> "النهارده هوريكم مشروعين AI Agents شغالين مع بعض.
> الأول على **n8n** — بيراقب داتا مزارع، بيحلّلها، وبياخد قرار إداري وبيبعت تقرير على الإيميل.
> والتاني على **UiPath** — بيستقبل الإيميل ده، يفهمه، يصنّفه، ويطلّع تقرير منظّم يرفعه على Google Drive.
>
> يعني إيميل اتكتب بواسطة Agent، واتقرا واتفرز بواسطة Agent تاني. يلا نشوفهم."

---

## ⏱️ 0:30 – 2:00 — n8n: المزرعة الذكية

*(شاشة: كانفاس n8n كامل)*

> "نبدأ بالـ n8n. الـ flow ده بيشتغل على 6 خطوات."

*(أشّر على كل نود وإنت بتتكلم)*

> "**أول خطوة** بتقرا داتا الحسّاسات من Google Sheets — رطوبة التربة، الحرارة، صحة الأوراق، استهلاك المياه لكل مزرعة.
>
> **تانية** — دي مش AI، دي JavaScript عادي. الكود ده بيجمّع الداتا: كام مزرعة، كام حدث خطورة عالية، متوسط الرطوبة، وبيرتّب المزارع حسب الأولوية. **ليه؟** عشان مبعتش للـ AI ألف صف خام — أبعتله خلاصة نضيفة. ده بيوفّر tokens وبيدّي نتيجة أدق."

*(افتح نود الـ AI Agent وورّي الـ prompt)*

> "**تالتة — الـ AI Agent.** شايفين التعليمات: *Use ONLY the supplied data* و *Never invent measurements*. والموديل على **Temperature = 0** عشان القرار يبقى ثابت مش عشوائي.
>
> وطالب منه يرجّع **JSON بشكل محدد** — مش كلام مرسل — عشان باقي الـ workflow يقدر ياخد قرارات بناءً عليه."

*(افتح نود Validate AI Decision)*

> "**رابعة — دي أهم نود في المشروع كله.** لو الـ AI رجّع JSON ناقص أو مكسور، الكود ده بيبني النتيجة من الداتا الحقيقية بدل ما الـ workflow يقع. يعني الأتمتة شغالة حتى لو الـ AI غلط."

*(أشّر على الـ IF والفرعين)*

> "**خامسة وسادسة** — لو فيه خطورة، يبني dashboard أحمر ويبعت تنبيه عاجل. لو الوضع تمام، يبعت تقرير إداري عادي."

## ⏱️ 2:30 – 4:15 — UiPath: فرز الإيميلات

*(شاشة: UiPath Studio Web — Agent Definition)*

> "دلوقتي الجزء التاني. الإيميل اللي وصل ده — مين هيقراه ويقرر يعمل بيه إيه؟"

*(افتح Edit I/O Schema → Output)*

> "الـ Agent ده **مش بيرجّع ملخص نصي** — بيرجّع **11 حقل منظّم**: الملخص، التصنيف، الأولوية، الـ sentiment، هل يحتاج رد، النقاط المهمة، المطلوب عمله، المواعيد، رد مقترح، ودرجة ثقة."

*(ارجع للكانفاس وأشّر على أداة Summarize Text)*

> "وعندي هنا أداة **Summarize Text** — وده الفرق بين مجرد استدعاء LLM وبين Agent حقيقي: الـ Agent هو اللي **بيقرر** ينادي عليها إمتى، مش أنا اللي قايلّه في الخطوة كام."

*(افتح الـ System Prompt وسكرول بسرعة)*

> "وقواعد الأولوية محددة بالظبط: Critical يعني عطل أو أمان أو ميعاد خلال 24 ساعة. High يعني طلب مباشر أو ميعاد خلال أسبوع. والـ Temperature كمان **صفر** عشان نفس الإيميل ياخد نفس التصنيف كل مرة."

*(افتح Main.xaml)*

> "والـ Workflow 6 خطوات بس:
> يجيب أحدث إيميل → يبعته للـ Agent → ياخد التقرير → يعمل ملف → يكتب فيه → يرفعه على Drive."

## ⏱️ 4:15 – 5:00 — الربط والخاتمة

*(دوس Debug on cloud)*

> "نشغّله دلوقتي — وأحدث إيميل في الـ Inbox هو تقرير المزارع اللي الـ n8n لسه باعته من شوية."

*(الكروت بتخضر — استنى)*

*(افتح Google Drive → افتح الملف)*

> "وده التقرير النهائي — ملخص، نقاط أساسية، مطلوب عمله، مواعيد، ورد مقترح."

*(وقفة بسيطة)*

> "خلّونا نلخّص اللي حصل: داتا في Excel → Agent حلّلها وكتب إيميل → Agent تاني قرا الإيميل وفرزه وطلّع تقرير → التقرير اترفع على Drive. **من غير ما حد يلمس حاجة.**
>
> وأهم درس اتعلمته من المشروعين: **الـ Agent لازم يرجّع بيانات منظّمة مش كلام**، عشان باقي الأتمتة تقدر تبني عليه قرارات فعلية.
>
> الكود والتفاصيل على GitHub في الوصف. شكراً."
